## 在黎明升起时坠落｜剧情线背景（官方梗概）
【01 星空啊，为纷乱千念濯洗】
- 你在涡心整理思绪。自从降落翁法罗斯，你已见证四次擢升，四场离别，但「开拓」仍未结束。与此同时，你的手机传来短信震动声。
- 或许赛飞儿是全翁法罗斯过得最自由的人，灾厄并不能阻止她对财富的渴望。你决定与赛飞儿会合，前往冥河不再被阻断的斯缇科西亚。
- 你来到斯缇科西亚，却没有见到赛飞儿的踪影。身后传来阵阵阴风，迷迷对迫近的气息有不妙的预感。
- 赛飞儿伪装成「盗火行者」，向你展示了一番「诡计」的神力。「谎言」只要被人相信，就能转化为现实。与此同时，你再次收到短信。
- 赛飞儿要求你先陪她打捞宝藏，之后会将你送去与白厄会合。命运的箴言为赛飞儿揭示：「汝将与贪婪同行，亦将亡于分文。」
【02 宝箱啊，兀自承装下前尘】
- 赛飞儿将打赌赢来的财宝交给阿格莱雅，想要买下店里最昂贵的衣装。阿格莱雅却只将一双金靴交给赛飞儿，称其受到「诡计」的祝福。
- 「贼灵」巴特鲁斯揭露故事的虚假，赛飞儿察觉到巴特鲁斯身上不太对劲。她决定将计就计，在寻宝中陪「巴特鲁斯」玩一会儿。
- 「贼灵」巴特鲁斯打开欧洛尼斯的灯塔，将光圈锁定在赛飞儿身上，以此帮助她蹚过河面。
- 赛飞儿将一枚水晶赏给巴特鲁斯，饰品在其佩戴的瞬间变为陶罐。诡计得逞的赛飞儿捧腹大笑，称：「人人信以为实，谎言即可成真。」
- 为保持寻宝的隐秘性，赛飞儿劝巴特鲁斯不要动用「扎格列斯之手」。想要「诡计」不败露，至少得先管好嘴巴。
- 赛飞儿与「贼灵」巴特鲁斯遭遇把守宝藏的怪物。赛飞儿对怪物发出挑衅，并让巴特鲁斯前去战斗。
- 巴特鲁斯挖掘宝藏，却只得到斯缇科西亚难民的日志。「贼灵」打听起赛飞儿在刻法勒祭司院当学徒的经历，激起赛飞儿的警觉。
- 赛飞儿被巨大箱子挡住去路。无奈之下，只好让巴特鲁斯启动「扎格列斯之手」来破坏路障。
- 通路打开后，赛飞儿假意要回答巴特鲁斯方才提出的问题。巴特鲁斯却声称不曾提问，赛飞儿大致确定个中蹊跷。
- 巴特鲁斯挖掘第三处宝藏，却找出一个金山羊面具。赛飞儿认出这是「黄金替罪羊」装置，让巴特鲁斯解开谜题。
- 赛飞儿揪出附着在巴特鲁斯身上的若虫。金丝向赛飞儿传递消息，称阿格莱雅即将离逝。黄金裔的使命需要赛飞儿，请尽快返回奥赫玛。
- 赛飞儿在黎明云崖的经历不曾向任何人提起，由此判断巴特鲁斯遭遇异常。她揭露「贼灵」实为扎格列斯，自己用诡计让泰坦骗过死亡。
- 阿格莱雅救助受伤的赛飞儿。赛飞儿觉得自己愧对黄金裔身份，总在做卑劣的事情。但阿格莱雅给予她发自内心的信任，邀其留在身边。
【03 识院啊，悠扬间评定今昔】
- 在征伐「天空」泰坦艾格勒之前，风堇回到树庭。作为天空一族的后人，「天空」的黄金裔，她缅怀自己在地面的生活回忆。
- 风堇的祖先「阳雷骑士」塞涅俄丝曾弑杀天空泰坦。为创造通往天空的彩虹桥，她必须获取先祖赐福。风堇在树庭遇到搜集资料的丹恒。
- 风堇召唤出裁判官克里斯普斯的英魂，表达归还「天空」火种的决心，取得其赐福。丹恒用「灵水」将风堇送去涡心，谒见下一位先祖。
- 经由法吉娜秘术创造、只能通过一人的灵水之门，风堇来到创世涡心。祭仪水盆旁，缇宝正与赛飞儿交谈。
- 赛飞儿即将离开奥赫玛，她将一份礼物交给缇宝，要求其天黑之后再打开。缇宝将创世涡心让给风堇，为其留出进行召唤仪式的场地。
- 风堇召唤出将军特克菈的英魂，谈论逐火的使命，取得其赐福。命运的箴言为风堇揭示：「在彩虹桥的尽头，天空之子将缝补晨昏。」
- 风堇回到树庭，向丹恒与小伊卡讲述与先祖的对话。丹恒从「天空」的预言中体会到悲伤，与风堇出发去悬锋城谒见最后一位天空先祖。
- 风堇召唤出祖母雅辛缇亚的英灵。雅辛缇亚曾代表昏光庭院参加悬锋祭典，在死斗中负于克拉特鲁斯。祖母为风堇讲述天空英雄的传说。
- 「天空」泰坦怒视晨昏后裔，「阳雷骑士」塞涅俄丝率领两位翼兽伙伴刺穿巨眼。苍穹破碎之际，塞涅俄丝与泰坦合体，再度撑起天空。
【04 书卷啊，可曾令锋刃回眸】
- 丹恒与来古士在列车坠落点交谈。丹恒猜想在「天空」火种归还后，翁法罗斯的隔绝状态便能打破。来古士检查车厢，寻求维修的方法。
- 来古士称只要中止协助逐火之旅，他能将你与丹恒送离翁法罗斯。丹恒认为不能抛弃黄金裔们，与此同时，元老院的刺客们将丹恒包围。
- 在神悟树庭，你将先前遭遇盗火行者的记忆复现，以此作为白厄的战斗训练。
- 在针对性训练中，白厄的战斗技巧大有长进。他已委托哈托努斯，为自己打造一柄趁手的神兵。训练结束后，白厄提议去友爱之馆看书。
- 你于友爱之馆中翻阅书籍，尽情满足自己的阅读趣味。饱览一番之后，你决定去看看白厄与迷迷在看什么书。
- 你悄悄靠近白厄，发现他在看与致富相关的书籍。白厄认为阿格莱雅之所以能成为优秀的领导者，一个重要的原因是她的家底相当殷实。
- 「耕耘月，幕匿时，宜食稻麦作物，忌垂钓……」迷迷似乎在看祭祀相关的书。发现你之后，迷迷害羞地跑开了。
- 「『君王』…『织者』…『羁客』…『医者』…」迷迷似乎在看卡牌相关的书。发现你之后，迷迷害羞地跑开了。
- 白厄也加入围观，你们发现迷迷在看《翁法罗斯占卜全书》。白厄想起昔涟，向你出示昔涟曾用的占卜牌。突然，友爱之馆内传来异动。
- 你与白厄被「清洗者」包围。白厄向你解释，「清洗者」是专门暗杀黄金裔的刺客部队。你做好战斗准备，但对方并未发起进攻。
- 缇宝带风堇选址，计划在奥赫玛重建「昏光庭院」，并谈论天空之民的历史。克莱门汀带来紧急消息，称阿格莱雅在云石天宫遭遇不测。
- 凯妮斯率「清洗者」与阿格莱雅对峙，揭露其力量衰退，并以公民的性命来胁迫阿格莱雅放弃生命。阿格莱雅选择拥抱预言，向其妥协。
【05 金丝啊，请喻救世者谶语】
- 来古士称「清洗者」会以炼金术传递记忆与身份，当前的「凯妮斯」已是第二十七任。克拉特鲁斯前来救援丹恒，称阿格莱雅已被杀害。
- 白厄击倒来犯之敌，「清洗者」队长却声称「拖延时间」的任务已经完成，率众撤退。白厄怀疑元老院另有所图，同时，手机传来振动。
- 白厄认为「清洗者」的实力不足以刺杀阿格莱雅，当下必须亲眼确认阿格莱雅的状况。他请缇宝尽力安抚公民，并与你即刻赶回奥赫玛。
- 阿格莱雅的神识以若虫形态与哈托努斯交谈，这意味着她的身形已经破碎。阿格莱雅将自身神性封存，以女孩赠送的髀石护身符为容器。
- 你与白厄回到奥赫玛，不安的情绪在圣城中蔓延。你们前去寻找缇宝，向其了解事况。
- 你们路遇丹恒。克拉特鲁斯称，阿格莱雅从黄金裔浴池坠落，心脏被「清洗者」的制式匕首刺穿。风堇作为医师宣告了阿格莱雅的死亡。
- 你们路遇风堇，得知她与缇宝、缇宁经历了阿格莱雅的最后时刻。风堇动用天空祝福，却仍无法逆转死亡，只能宣告阿格莱雅的离去。
- 你们找到缇宝。缇宝劝白厄不要自责，逐火的旅途仍将继续，奥赫玛与黄金裔呼唤引路人。阿格莱雅留下一封卷轴，托付缇宝交与白厄。
- 阿格莱雅留下遗言，坦承为清除圣城暗处的威胁而自毁设局，将守护翁法罗斯的使命托付白厄。白厄接过领袖重任，将以演讲团结公民。
- 哈托努斯将形制如盗火行者之剑的神兵带给白厄，将其命名为「侵晨」。与武器一同交付白厄的，还有封存阿格莱雅残留神性的护身符。
- 白厄坦言阿格莱雅的陨落，希望众人以团结来超越复仇。白厄愿以毫无保留的深信来抵御恶意，与圣城全体公民一同成为「更好的人」。
- 白厄回忆逐火之旅，与缇安、那刻夏等同伴诀别，接受阿格莱雅「将创世权交予凡人」的嘱托。昔涟出现于记忆终幕，称白厄从未改变。
- 赛飞儿回到奥赫玛，伫立于黎明云崖。时移事迁，她不禁回想起千年往事。
- 赛飞儿想要窃取「全世宝石」以救济贫民。阿格莱雅认可其同情心，但认为「诡计」会有更大的作用。某些时候，谎言可以比坦诚高贵。
- 白厄请求赛飞儿保护刻法勒的火种，切勿令其落入元老院或盗火行者之手。
【06 诗者啊，从我处诉说天空•上】
- 你与迷迷来到黎明云崖，发现此处聚集起许多民众。奥赫玛于此为征伐「天空」的黄金裔们送行。
- 在击败「天空」之后，你与丹恒就有机会重返家园。白厄赞许你为翁法罗斯做出的贡献，希望将告别留给未来，当下准备继续并肩作战。
- 在民众的欢呼声中，风堇登上长阶。她已经得到天空一族先祖的赐福，准备好引领人子重返天空。
- 你们在黎明云崖高台完成集结，即将踏上讨伐「天空」的征程。风堇吟唱祷言，以天空赐福创造出连接天地的彩虹桥。
- 在先祖赐福的助力下，风堇于黎明云崖架设起通往天空的彩虹桥。「各位，请同我一起飞翔吧。」
- 你们来到艾格勒的天空堡垒。曾信仰「天空」的晖之民与雨之民于此争斗，塞涅俄丝亦于此弑杀泰坦，由此开始逐火的时代。
- 你们在黑暗环境中探索。风堇建议重启连接翁法罗斯天幕的「天象画壁」，来提供前行必要的光源。
- 风堇尝试启动浑象仪，但她需要一些前人智慧的帮助。风堇拜托你和迷迷，收集散落周围的记忆碎片。
- 往世的晖之民记忆宣称：「伟大的艾格勒已在金色的云朵间留下了它的化身印记……」白厄猜想这与天象画壁有关。
- 往世的雨之民记忆质问：「塑造天空的艾格勒，为何要回避乌云的追赶？」风堇认为这会是一条线索。
- 在浑象仪前，记忆残像揭露出雨之民所吟唱的天象画壁密钥，以及天空部落之间残酷的内斗。风堇记住吟唱内容，尝试启动天象画壁。
- 天象画壁成功启动，艾格勒的「化身印记」随之出现。你们需要使用其他浑象仪改变天象以困住泰坦，「西风罗盘」可以为此创造通路。
- 丹恒注意到平台下方的黄金池，风堇称那是驱动晨昏之眼的神性能源。你与风堇尝试使用西风罗盘创造微型彩虹桥。
- 彩虹桥出现的同时，一匹灵体状态的带翼天马随之显形。它似乎没有敌意，并引领着你们前行。
- 灵体天马骤然消失。风堇猜测其为露奈比斯的幻影，「阳雷骑士」塞涅俄丝的翼兽伙伴之一。无论如何，你们要去往晨昏之眼的核心。
- 露奈比斯引领你们找到被黑潮侵蚀的索拉比斯，请求给予同伴以解脱。风堇决定摧毁索拉比斯扭曲的躯壳，以此释放其顽强的灵魂。
- 索拉比斯和露奈比斯的灵魂得以重逢，而艾格勒的印记再次飞逃。索拉比斯认可你们挑战「天空」的决意，引领你们前往猎神。
- 索拉比斯引领你们到达第二气象单元，晖之民的殿堂。索拉比斯称艾格勒所逃避的并非云雨，而是蛰伏于阴影中的黑潮。
- 风堇尝试转换天气，天象画壁却没有反应。丹恒推测是装置老化，需要将殿堂两侧的电路加以维修。
- 天象画壁转阴，艾格勒的印记再次消失，露奈比斯会继续追踪泰坦。而在离开此地前，风堇请求迷迷重现记忆，揭开天空之民的历史。
- 「阳雷骑士」塞涅俄丝痛斥压迫同胞的晖之民，指出正是艾格勒的「神罚」将天空封锁。塞涅俄丝相信「再创世」神谕，踏上弑神之路。
- 你们与露奈比斯会合。被黑潮腐蚀的艾格勒召集眷属，试图将你们围困。
- 艾格勒的印记再次逃逸。在露奈比斯的引领下，你们前往下一处西风罗盘开辟通路。
- 壁画上描绘着「天空」泰坦艾格勒，即「晨昏之眼」。这是艾格勒在神话中最常见的形态，不出意外的话，你们很快就能一睹它的真容。
- 彩虹桥再度显现，你们跟随露奈比斯追击「天空」泰坦。
- 露奈比斯称，塞涅俄丝的父亲是晖之民战士，母亲则是雨之民祭司。塞涅俄丝因血统和黄金裔身份遭到驱逐，在旅居中结识两位翼兽。
- 你们进入第三气象单元。白厄清除浑象仪周围的黑潮怪物，与祷言装置的交互则由你负责。
- 被黑潮侵蚀的天空眷属显得更为强大。面对无法疗愈的侵蚀，风堇认为最温柔的做法是使其灵魂获得体面的解脱。
- 浑象仪缺乏能源驱动。丹恒注意到殿厅两侧有一些巨大物体，或许与能源有关。白厄拜托你操控「扎格列斯之手」将其修复。
- 天象画壁再次转阴，无处可躲的艾格勒印记只好垂直向上。露奈比斯称艾格勒自身也无法突破天幕，丹恒推测封锁天界者可能另有其人。
- 「阳雷骑士」塞涅俄丝怜悯懦弱的雨之民，指出泰坦的偏袒才是部族压迫之源。塞涅俄丝决心弥合阴晴晨昏，将公正与博爱自天空洒下。
- 艾格勒的印记飞向穹顶，塞涅俄丝曾在那里带给泰坦致命一击。「天空」的陨落令众生恐惧，而此后之事，与世界历史的记载截然不同。
- 艾格勒切断彩虹桥，拼尽最后手段阻止你们靠近。然而在风堇的努力下，彩虹桥再次被修复。
- 通路已成，此去再无你们与「天空」之间的阻碍。塞涅俄丝所期待的能取回火种的天空之子，而今即将来到她面前。
- 你们来到穹顶，众多受黑潮侵蚀的士兵在此聚集，在风堇阅读长眠于此的记忆前，你们仍有一场恶战。
- 你们来到穹顶。作为预言中的天空后裔，风堇得以阅读封存于浑象仪的记忆，由此揭示塞涅俄丝弑神之后，天空之民所遭遇的一切。
【07 石板啊，为何罔闻那灯影】
